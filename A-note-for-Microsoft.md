## 🪟 A Tiny Message for Microsoft

Hey Microsoft. 👋

Windows is impressive.

But EggOS was born from a few things that make me go:

**“Bro, why?”** 💀

* 🕵️ **Privacy concerns** — there's a lot of telemetry and connected functionality that users may not want.
* 🧱 **Bloat** — sometimes the OS feels like it comes with an entire shopping mall when I only asked for a house.
* 🗑️ **Features disappearing or changing** — old Windows features and familiar parts of the experience have been removed, replaced, or redesigned over the years.
* ☁️ **More cloud integration** — sometimes I just want my computer to be a computer.
* 🔐 **More platform control** — I'd rather have an OS where I have more say over what runs on my own hardware.

So I made EggOS.

Not because Windows is incapable.

Not because Microsoft can't make good software.

But because **I want another choice.**

> **You can keep Windows. I'll build my egg.** 🥚

No corporate war.

No dramatic declaration of independence.

Just another operating system trying to exist.

And hopefully one that doesn't need seventeen menus to find the setting I used yesterday. 💀
