# 🤝 Contributing to EggOS

Want to help build EggOS? Awesome! 🥚

## 🛠️ Ways to Contribute

- 💻 Code
- 📱 Device/HAL support
- 🔧 Drivers
- 📦 Packages
- 📖 Documentation
- 🐛 Bug reports
- 💡 Ideas

## 🚀 Getting Started

1. Fork the repository.
2. Make your changes.
3. Test them.
4. Open a pull request.
5. Explain what you changed and why.

Thanks for helping build EggOS! 🥚🚀
