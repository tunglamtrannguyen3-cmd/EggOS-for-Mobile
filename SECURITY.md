# 🔒 EggOS Security

Security is important to EggOS and its users. 🥚🛡️

## 🚨 Reporting a Vulnerability

**Please do not publicly disclose security vulnerabilities.**

If you find a security issue:

* Report it privately to the EggOS maintainers.
* Include a clear description of the issue.
* Explain how it can be reproduced, if safe to do so.
* Include the affected version or component.
* Give maintainers reasonable time to investigate and fix it.

## ⚠️ Please Don't

* Publish working exploits before a fix is available.
* Attack EggOS users, infrastructure, or devices.
* Access data that doesn't belong to you.
* Use security testing to cause unnecessary damage.

## 🛠️ After Reporting

The maintainers will investigate the report, work on a fix, and coordinate public disclosure when appropriate.

Thank you for helping keep EggOS secure! 🛡️🥚
