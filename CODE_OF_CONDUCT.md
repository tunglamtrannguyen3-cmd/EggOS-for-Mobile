# 🥚 EggOS Code of Conduct

Welcome to EggOS! 🥚📱

EggOS is built by people who want to **learn, experiment, and build together**.

## 🤝 Be Respectful

* Treat everyone with respect.
* Give constructive feedback.
* Disagree with ideas, not people.
* Respect contributors of all experience levels.
* Credit other people's work.

## 🚫 Don't

* Harass, threaten, bully, or discriminate.
* Share someone's private information.
* Make personal attacks.
* Intentionally disrupt the project.
* Submit malicious code.
* Publicly expose security vulnerabilities.

## 🛠️ Technical Disagreements

Different opinions are normal!

Keep discussions focused on **evidence, testing, security, and the project's goals**.

## 🔒 Security

Found a vulnerability? Please report it privately using `SECURITY.md` instead of opening a public issue.

## ⚖️ Enforcement

Maintainers may remove content or restrict participation when this Code of Conduct is violated.

## 🌱 Final Rule

**Build things. Learn things. Help each other. Make EggOS better.** 🥚🚀

Thanks for being part of the EggOS community! ❤️
