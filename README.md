**An experimental operating system for mobile devices.**

There's also a PC version planned, but I'm currently too lazy to work on it. 🛏️

## 🚀 Development

Development is planned to start on **September 13, 2026**, when my GitHub Copilot limit resets.

Whether I actually have enough discipline to finish it is another question. 💀

## 🤔 Why EggOS?

I'm making EggOS because I want more control over the software ecosystem I build for.

I'm particularly concerned about changes to Android's app-distribution and developer requirements that could give platform owners more control over how developers publish and distribute apps.

So instead of just complaining about it...

**I decided to make an OS.**

## 🧑‍💻 Credits & Borrowed Code

EggOS may incorporate or adapt existing open-source projects when writing everything from scratch would be impractical.

Current projects/components I'm looking at include:

* **Limine** — bootloader
* **NASA projects** — software/components for possible integration
* **Linux kernel** — selected code or concepts where appropriate

## 🛠️ Planned Direction

EggOS is intended to eventually support:

* 📱 ARM64 mobile hardware
* 💻 PC hardware
* 🔐 Secure/verified boot
* 🧩 A modular boot architecture
* 🖥️ Custom UI
* 💻 Linux-style CLI tools
* 🔒 Modern cryptography and secure networking
* 📦 An EggOS application ecosystem

The goal:

> **Build an operating system I actually control.**
